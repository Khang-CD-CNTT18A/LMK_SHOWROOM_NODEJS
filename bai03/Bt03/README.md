# BÀI 03 - BÀI TẬP 03

## 1. Giới thiệu
Chương trình sử dụng module `fs` trong Node.js để thao tác với tập tin.

Các chức năng:
- Tạo tập tin `thongtin.txt`.
- Ghi họ tên và mã sinh viên vào tập tin.
- Đọc và hiển thị nội dung tập tin.
- Sử dụng `appendFile()` để ghi nối tên lớp.
- Đọc lại tập tin sau khi cập nhật.

## 2. Cấu trúc thư mục

```text
Bt03/
├── bai03.js
├── thongtin.txt
└── README.md
```

## 3. Lệnh thực hiện

```bash
node bai03.js
```

## 4. Kết quả

Chương trình tạo tập tin, ghi thông tin sinh viên, ghi nối tên lớp và hiển thị nội dung sau khi cập nhật.

## 5. Hình ảnh minh chứng

Bổ sung ảnh chụp:
- Mã nguồn bai03.js.
- Terminal khi chạy chương trình.
- Nội dung tập tin thongtin.txt sau khi cập nhật.

## 6. Kết luận

Đã hoàn thành bài thực hành sử dụng module fs để tạo, đọc và ghi nối nội dung tập tin trong Node.js.
