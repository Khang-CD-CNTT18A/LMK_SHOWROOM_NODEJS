# BÀI 03 - BÀI TẬP 01

## 1. Giới thiệu
Chương trình quản lý danh sách 5 sinh viên bằng JavaScript và Node.js.

## 2. Nội dung thực hiện
- Sử dụng class để khai báo lớp SinhVien.
- Sử dụng constructor để khởi tạo thông tin sinh viên.
- Tạo danh sách gồm 5 sinh viên.
- Sử dụng arrow function và filter() để lọc sinh viên có điểm từ 5 trở lên.
- Sử dụng console.log() để in kết quả.

## 3. Cấu trúc thư mục

```text
Bai03/
└── Bt01/
    ├── bai01.js
    └── readme.md
```

## 4. Lệnh chạy chương trình

```bash
node bai01.js
```

## 6. Kết luận

Đã hoàn thành bài tập sử dụng class, constructor, mảng và arrow function để lọc danh sách sinh viên đạt yêu cầu.
