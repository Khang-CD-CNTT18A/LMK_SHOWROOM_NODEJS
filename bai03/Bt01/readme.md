# BÀI 03 - BÀI TẬP 01

## 1. Giới thiệu

Bài tập xây dựng chương trình quản lý danh sách sinh viên bằng JavaScript và Node.js.

Yêu cầu chương trình:
- Khai báo class `SinhVien` bằng từ khóa `class`.
- Sử dụng `constructor` để khởi tạo thông tin sinh viên.
- Tạo danh sách gồm 5 sinh viên.
- Sử dụng arrow function kết hợp với `filter()` để lọc sinh viên có điểm từ 5 trở lên.
- Sử dụng `console.log()` để hiển thị kết quả.

## 3. Các bước thực hiện

**Bước 1:** Mở Terminal tại thư mục `Bt01`.

**Bước 2:** Chạy chương trình bằng lệnh:

```bash
node bai01.js
```

**Bước 3:** Kiểm tra kết quả hiển thị trên Terminal.

## 4. Kết quả chạy chương trình

```text
DANH SACH SINH VIEN DAT YEU CAU:
Ma: SV01 | Ho ten: Nguyen Van An | Tuoi: 20 | Diem: 8
Ma: SV03 | Ho ten: Le Van Cuong | Tuoi: 19 | Diem: 7
Ma: SV04 | Ho ten: Pham Thi Dung | Tuoi: 20 | Diem: 5
```

Kết quả: Có 3 sinh viên đạt yêu cầu với điểm số từ 5 trở lên.
