
# BÀI 02: VIẾT ỨNG DỤNG ĐẦU TIÊN VỚI NODE.JS

## 1. Mục tiêu
- Tìm hiểu module HTTP trong Node.js.
- Tạo máy chủ HTTP bằng Node.js.
- Sử dụng cổng 8080.
- Hiển thị nội dung HTML trên trình duyệt.

## 2. Các file trong bài
- myFirstNode.js: Chương trình tạo máy chủ Node.js.
- README.md: Mô tả nội dung bài tập.

## 3. Công nghệ sử dụng
- Node.js
- JavaScript
- HTTP Module

## 4. Cách chạy chương trình

Mở Terminal tại thư mục Bài 02 và chạy:

    node myFirstNode.js

Sau đó mở trình duyệt:

    http://localhost:8080
