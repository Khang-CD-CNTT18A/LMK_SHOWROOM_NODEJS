## BÀI 01: CÀI ĐẶT NODE.JS LTS VÀ CHƯƠNG TRÌNH HELLO.JS

### Nội dung thực hiện
- Cài đặt Node.js.
- Kiểm tra phiên bản Node.js bằng `node -v`.
- Kiểm tra phiên bản npm bằng `npm -v`.
- Khởi tạo project bằng `npm init -y`.
- Xây dựng và chạy chương trình Node.js đầu tiên.

### Cấu trúc bài tập
- Thư mục `baitap1`: Chứa mã nguồn Bài 01.
- File `hello.js`: Chương trình Node.js.
- File `package.json`: Thông tin dự án.
