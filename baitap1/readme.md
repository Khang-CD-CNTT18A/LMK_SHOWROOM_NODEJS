# BÀI TẬP 01: CÀI ĐẶT NODE.JS LTS VÀ CHƯƠNG TRÌNH HELLO.JS

## 1. Mục tiêu
- Cài đặt môi trường Node.js.
- Kiểm tra phiên bản Node.js bằng lệnh `node -v`.
- Kiểm tra phiên bản npm bằng lệnh `npm -v`.
- Khởi tạo project bằng lệnh `npm init -y`.

## 2. Các file trong bài
- `hello.js`: Chương trình Node.js đầu tiên.
- `package.json`: Thông tin project.
- `package-lock.json`: Quản lý phiên bản các thư viện.

## 3. Cách chạy chương trình

Mở Terminal tại thư mục Bài 01 và chạy:

```bash
node hello.js
```

## 4. Kết quả
Chương trình chạy thành công trên môi trường Node.js.
